# Сверка с ТЗ

## Шаги

1. Определи объём: номер этапа (1–4) или требование (`FR-3`, `FR-2.4`).
2. Прочитай нужный раздел `голосовой_rag.org` (п. 4–5 и таблица этапов в п. 11). Для поиска можно делегировать субагенту `spec-navigator`.
3. Для каждого подпункта найди в коде реализацию и тест (`grep` по эндпоинтам, env-переменным, именам классов).
4. Выведи таблицу:

   | Требование | Статус | Где в коде | Тест | Комментарий |
   |------------|--------|------------|------|-------------|

   Статус: ✅ выполнено / 🟡 частично / ❌ нет.
5. Отдельно — критерий приёмки этапа из п. 11: выполнен или нет и чего не хватает.
6. Не отмечай ✅ без найденного кода; при сомнении — 🟡 с объяснением.
